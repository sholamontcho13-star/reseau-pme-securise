# Réseau sécurisé d'une PME (siège + agence)

Projet personnel de conception et de sécurisation du réseau d'une PME fictive,
réalisé avec Cisco Packet Tracer.

## Contexte
Alpha Conseil, cabinet de conseil de 45 personnes, dispose d'un siège et d'une agence.
Son réseau doit être segmenté, sécurisé et résilient.
Voir le [scénario complet](docs/scenario.md).

## Objectifs
- **Segmentation** : séparer utilisateurs, serveurs, invités, DMZ et administration
- **Sécurité** : durcir les équipements et contrôler les accès
- **Résilience** : maintenir la liaison entre les sites en cas de panne
- **Preuves** : tester et documenter chaque mesure

## Outils
- Cisco Packet Tracer
- GitHub (documentation et versionnement)
